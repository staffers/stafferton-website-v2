Usage notes


    
Typography. All assets use Sen 700. Each SVG includes an @font-face rule loading Sen from jsdelivr's fontsource mirror — works when the SVG is inlined in HTML. For best reliability, also load Sen 700 in your site's CSS:

    
@import url('https://fonts.googleapis.com/css2?family=Sen:wght@700&display=swap');


    
Backgrounds. The primary logo uses currentColor for the letters that aren't teal. Set CSS color on the parent — #C1C1C1 on dark backgrounds, #3E3E3E on light — and the same SVG renders correctly in both. Slightly softening the non-accent letters lets the teal S, E, O carry more visual weight. Both icon variants use hardcoded fills and work on any background.


    
/* Dark sections — header, dark mode, social cards */
.logo-on-dark { color: #C1C1C1; }

/* Light sections — body, decks, email signatures */
.logo-on-light { color: #3E3E3E; }


    
Inlining vs img tag. Inline the SVG directly in your HTML for full control and font support. If using <img src="...">, the @font-face inside the SVG may be blocked by the browser's CSS sandbox — load Sen on the parent page instead.


    
Favicon export. For PNG favicons (16, 32, 48, 180px), use stafferton-favicon.svg and convert to PNG via your design tool of choice (Figma, Illustrator, or a CLI like rsvg-convert). Add the resulting PNGs to /public and reference them from your HTML head.
