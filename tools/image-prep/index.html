What this tool does

  • Resizes images to useful web dimensions.
  • Converts to WebP, JPEG or PNG using your browser.
  • Lets you balance visual quality against page weight.
  • Removes metadata because a fresh output file is created from image pixels.

Practical image guidance

  • Use WebP for most photographs and website graphics.
  • A 1600 px maximum width is usually enough for a full-width website image.
  • Keep PNG for transparency or graphics that need lossless output.
  • Animated images export as a single static frame.
