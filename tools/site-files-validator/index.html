What is checked

  • HTTP status and redirects for robots.txt and sitemap files.
  • User-agent groups, Sitemap directives and site-wide blocking.
  • XML sitemap root type, namespace, location count and duplicates.
  • Invalid locations and URLs pointing to another host.

What is not checked

The validator does not crawl every sitemap URL, render pages, assess URL quality or confirm whether Google has indexed a page. Large sitemap files are checked up to the first 1 MB.
